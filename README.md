# Шеф из холодильника / ФЕКО Кук

ИИ-шеф: вносишь продукты из холодильника — получаешь блюда по приёмам пищи с КБЖУ, шагами и авторскими фантазиями. Плюс поиск рецептов, решатель «Не знаю, чего хочу», вкусовой квиз, программы питания «Марафон» на 14–60 дней.

- Открыть: **https://efefelov.github.io/feco-kook/** (после включения Pages)
- Статус: релизная статическая сборка (GitHub Pages, работает без сервера)
- Стек: React 18 + TypeScript + Vite; ИИ — Z.ai (OpenAI-совместимый API, вызовы из браузера)
- Данные пользователя (кладовая, история, программы, профиль КБЖУ) — localStorage/IndexedDB, ничего не уходит на серверы

> Исходники — в репозитории `feco-kook-src` (частный), здесь — релизная сборка `gh-pages`.
> Направление продаж: ниша 2.8 «ФЕКО Кук (ИИ-рецепты)», журнал `D:\ФЕКО\sales\deals.json`.
